# arXiv submission package

| File | Purpose |
|---|---|
| `main.tex` | Full manuscript (self-contained; bibliography inline via `thebibliography`, so no BibTeX run is needed) |
| `figures/` | Fig. 1, Fig. 2a–c and Fig. 4a–b as PNG, taken from the Word v2 manuscript; Fig. 3 (`fig3_shap.pdf`) regenerated by `review/fig_shap_normalised.py` |
| `main.pdf` | Compiled PDF, for checking only (arXiv builds its own copy from the source) |
| `arxiv_submission.tar.gz` | What you upload: `main.tex` plus `figures/` |

## Build locally

```bash
latexmk -pdf main.tex
```

This was tested with TeX Live 2023 (pdfLaTeX). The packages used are standard and all available on arXiv: authblk, natbib, subcaption, tabularx, booktabs, lmodern and hyperref.

## Upload steps
1. arxiv.org → Submit → upload `arxiv_submission.tar.gz`.
2. Primary category: **eess.SY** or **cs.LG**. Suggested cross-lists: eess.SP, stat.ML.
3. Licence: CC BY 4.0 is recommended if a later journal submission is planned (check the target journal's preprint policy first).
4. Paste the abstract from `main.tex` without the LaTeX markup. Change `R\'eunion` to `Réunion`.
5. Before uploading, resolve the items marked **[AUTHOR]** in `../review/UPDATE_NOTES.md`, then rebuild the tarball:

```bash
tar czf arxiv_submission.tar.gz main.tex figures
```
